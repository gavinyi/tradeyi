# 欧易 USDT 永续合约模块设计

## 安全边界

- 仅支持欧易 Demo Trading，继续强制 `x-simulated-trading: 1`。
- 首版仅支持 `*-USDT-SWAP`，不支持币本位、交割合约或实盘。
- 默认逐仓 `isolated`、净持仓 `net_mode`、杠杆 2 倍，上限 3 倍。
- 合约模块使用独立策略 ID `crypto_volatility_swap`、独立虚拟持仓和独立服务。
- 平仓订单必须携带 `reduceOnly=true`，开仓订单不得携带该标志。
- 下单数量为合约张数，必须使用目录中的 `ctVal`、`lotSz`、`minSz` 换算。

## 功能范围

1. 合约账户余额、持仓、保证金、未实现盈亏和强平价格。
2. 永续合约自选、精确搜索和逐项移除。
3. 双向波动率突破策略：向上开多、向下开空、止损/盈利保护/反转平仓。
4. Shadow 与 OKX Demo 两种执行模式。
5. 独立最大杠杆、单笔保证金、最大持仓数和总保证金限制。
6. 独立持续服务、决策日志、订单、成交和策略复盘。

## 状态机

```text
空仓 -> 开多/开空 -> 持仓管理 -> reduceOnly 平仓 -> 冷却 -> 空仓
          |             |
          +--阻断-------+
```

净持仓不允许同一标的同时持有多空。反向信号只能先平现有仓位，下一轮才能反向开仓。

## 页面

- 合约账户总览：权益、合约持仓、Shadow 持仓、待成交、历史订单和成交。
- 永续合约策略：自选、运行模式、杠杆、风险参数、单轮扫描和持续服务。
- 合约策略复盘：信号、执行、持仓和阻断原因。

## 验收

- 任何非 `*-USDT-SWAP` 标的在模型层拒绝。
- 杠杆超过配置上限拒绝。
- 平仓缺少 `reduceOnly` 拒绝。
- Shadow 多空仓位使用有符号张数并能正确平仓。
- 欧易私有接口只读验收通过，模拟下单默认关闭。
# 2026-07-26 合约雷达与量化总览增补

永续合约模块已从固定自选扫描升级为完整闭环：

1. 合约雷达只扫描配置的候选池，并采用轮转游标控制每轮请求量。
2. 候选按波动扩张、Z 值、成交量、盘口价差、资金费率和未平仓量展示并排序。
3. 只有策略信号、资金费率和盘口流动性同时合格时，才允许自动加入。
4. 自动加入的标的记为“雷达托管”；人工加入的标的记为“固定自选”。
5. 雷达托管标的连续多轮失效，且没有持仓和待成交订单时，才自动退出。
6. 固定自选不会被雷达自动删除；有仓位或待成交订单的标的也不会被清理。
7. 新增“合约量化总览”，统一展示雷达流水线、策略决策、Shadow/欧易
   Demo 持仓、待成交订单、服务心跳和阻塞诊断。
8. 固定自选即使绕过雷达，开仓前仍会执行资金费率和盘口价差保护。

以上规则借鉴成熟量化系统将市场发现、信号、风险、执行和生命周期解耦的设计。
当前仍只支持欧易 Demo 与 Shadow，不会连接真实交易。
