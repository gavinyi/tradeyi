# 研究数据与回测 V2 使用说明

## 安全边界

研究数据系统不会改变交易出口。账户、持仓、订单、成交以及实时委托价格只来自富途，券商对象仍固定使用 `TrdEnv.SIMULATE`。Alpaca、Yahoo 和 Qlib 只提供历史研究能力，其数据和预测不能直接变成订单。

## 数据源分工

| 数据源 | 用途 | 限制 |
|---|---|---|
| 富途 | 主历史行情、模拟交易真相源 | 受账户行情权限和接口频率限制 |
| Alpaca | 美股历史缺口补全和第二来源校验 | 免费股票数据是 IEX，不代表全市场成交量 |
| Yahoo/yfinance | 三级研究备用和快速核对 | 非官方接口，只用于个人研究 |
| Qlib | 因子、模型、实验和预测研究 | 可选依赖；输出永远是不可执行研究信号 |

## 可选安装

只使用富途时无需安装任何新依赖。

```bash
uv sync --extra marketdata
```

以上命令安装 Yahoo 备用源。Qlib 单独安装：

```bash
uv sync --extra research
```

Alpaca 使用以下环境变量：

```dotenv
ALPACA_API_KEY=你的研究数据key
ALPACA_API_SECRET=你的研究数据secret
```

它们不能填写在 Streamlit 页面，也不会写进 SQLite、Parquet manifest 或日志。

## 数据研究中心

进入“研究与系统 → 数据研究中心”。页面不会因为打开或切换视图就下载行情。

### 数据源状态

展示每个 Provider 是否已配置、可选包是否安装，以及其用途限制。这里的“可用”表示适合被显式调用，不代表交易所权限一定覆盖所选标的和日期。

### 数据目录

输入代码、日期和来源顺序后点击“开始补全并保存”。自动模式依次尝试：

1. 富途；
2. Alpaca；
3. Yahoo。

前一来源限频、无权限、无数据或网络失败时才会尝试下一来源。页面会显示每次尝试和最终实际来源。

数据保存在：

```text
data/market-data/bars/symbol=US_AAPL/year=2026/part.parquet
data/market-data/bars/symbol=US_AAPL/year=2026/manifest.json
```

同一来源如果混入不同复权口径会被拒绝。不同来源会分别保留；策略回测默认按富途、Alpaca、Yahoo 的优先级，每个交易日只选择一条规范记录。

### 数据质量

页面检查重复数据、被隔离价格、缺失工作日和两个来源之间的收盘价差异。缺失工作日指标没有扣除美国交易所假日，只用于发现异常长缺口，不应直接作为交易日数量。

来源价格差异超过 3% 时标记为 `QUARANTINED`。应先检查拆股、分红和复权口径，不能简单选择对策略更有利的来源。

### 回测 V2

回测仍遵循 T 日收盘产生信号、T+1 开盘成交。新增：

- CAGR、年化波动率、Sharpe、Sortino、Calmar；
- 最大回撤及持续时间；
- 胜率、Profit Factor、每笔期望值和换手率；
- 平均/最大仓位暴露；
- SPY 基准收益、超额收益、Alpha、Beta 和捕获率；
- 可选成交量参与率和部分成交记录；
- Walk-forward、固定随机种子 Bootstrap，以及 1、1.5、2 倍滑点压力测试。

如果本地没有 SPY 规范历史，基准指标显示为零；先在数据目录补全 SPY 后再生成正式研究证据。

## Qlib 边界

`QlibResearchAdapter` 可以把规范日线转换成以 `instrument/datetime` 为索引的研究 Parquet，并把模型预测转换成统一研究信号。每条信号都包含：

- 模型版本；
- 数据版本；
- 生成时间；
- `signal_type=RESEARCH_ONLY`；
- `executable=false`。

这些信号必须先进入实验登记、样本外验证、审批和现有风控，不能绕过统一交易服务。

## 期权历史证据

期权回测仍使用系统实际积累的富途快照，并按卖一开仓、买一退出。系统现在会先检查：

- 可成交盘口条数；
- 覆盖交易日；
- GOOD/DEGRADED 比例；
- 平均 bid/ask 价差；
- Delta、DTE、Call/Put 和流动性分桶。

不足时返回 `INSUFFICIENT_EVIDENCE`，明确显示还缺多少样本和交易日。免费数据不能提供可靠、完整的长期 OPRA 历史盘口，因此系统不会用中间价或股票代理收益伪装成可成交期权回测。

## 建议运行方式

- 统一交易服务会在非交易时段每天增量补全 SPY、普通自选、Core Satellite、财报 Gamma 和波动率自选标的最近 14 天富途日线；单个无权限标的不会中断整批任务。
- 也可以在数据研究中心手工选择更长日期范围和备用来源补全。
- 正式验收只使用已经记录数据版本和内容哈希的结果。
- 每次策略参数变化重新运行 Walk-forward 和压力测试。
- 持续运行统一交易服务，以分钟级积累已配置期权和持仓期权的真实盘口快照。
