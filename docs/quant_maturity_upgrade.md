# 量化系统成熟度升级记录

本轮将成熟量化系统的七项能力映射到现有实现：

1. **行情数据层**：`CanonicalMarketDataStore` 使用本地 Parquet 分区和 manifest，`MarketDataRouter` 支持多源降级，新增 `freshness_report()` 输出数据新鲜度和质量等级。
2. **成交模型**：股票、期权和币回测均支持手续费与滑点；模拟执行保留限价、重报价、部分成交和取消状态。
3. **期权风险表达**：订单和持仓归因已关联 Delta、Gamma、Vega、Theta，期权候选包含 IV/RV、期限和流动性校验。
4. **组合预算**：策略预算表支持 Core、Satellite、期权和现金缓冲的独立预算，组合风险模块负责集中度与 Greeks 门控。
5. **成交质量**：执行质量报表现在包含成交率、部分成交率、撤单率、P95 等待时间、手续费、成交名义金额和不利滑点。
6. **参数稳定性**：股票、期权、组合和币策略已有 Walk-forward、样本外窗口、滑点敏感性和 bootstrap 评估。
7. **逐笔归因**：`attribution_report()` 按策略/标的 FIFO 匹配开平仓，拆分已实现、未实现、手续费、滑点和 Greeks 暴露。

## 运行原则

- 富途负责实时交易和盘口；本地仓库负责研究数据复现。
- 数据源冲突时进入隔离状态，不自动混合使用。
- 回测必须显式填写手续费、滑点和成交假设。
- 任何策略上线前必须查看样本外结果和成交质量，而不是只看总收益。
- 组合预算优先于单策略信号，强信号也不能绕过组合级风险门控。
