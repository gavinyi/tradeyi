# 页面耦合排查与拆分规范

## 排查结论

本轮按页面中的输入控件、表格、按钮和展开区数量做了一次横向扫描。高耦合页面主要集中在策略参数页、风控页和期权执行页。

## 已处理页面

### 波动率策略高级配置

已拆为：

- 常用数据：雷达状态、自动策略、最近执行、最近扫描、已保存策略摘要和常用入口。
- 参数配置：标的搜索、雷达预算、候选生成、入场参数、退出保护、分批止盈、冷却、清理和独立运行调试。

### 财报 Gamma 策略

已拆为：

- 常用数据：Gamma 标的数量、自动策略数量、最近执行记录、已保存策略摘要。
- 参数配置：标的搜索、自动财报日历、候选生成、策略保存、清理和隔离调试。

### 风控中心

已拆为：

- 常用状态：急停状态、核心风控阈值、组合风险入口。
- 参数配置：急停操作、集中度、订单执行、期权 Greeks、策略资金配额和自动校准建议。

### 交易配置

已有页签结构：

- 当前配置：当前标的、Core Satellite 预算和执行节奏。
- 查找并添加：加载证券目录、搜索和新增标的。

本轮补充了使用提示，明确日常查看和新增标的的入口区别。

以下页面已经使用页签或单一职责结构，暂不做大改：

- 策略与资金控制：服务控制、策略调度、策略资金、收益归因、实验版本、插件协议已经分开。
- 期权组合执行：创建组合、结构模板、组合管理、候选生成、组合回测、执行质量、故障演练、执行审计、安全规则已经分开。
- 波动率策略总览：已定位为日常运营台，不放低频参数。

## 后续页面规则

所有复杂页面默认按以下方式拆分：

1. 第一个页签必须是“常用数据”或“常用状态”，只放日常判断需要的信息。
2. 配置项放到第二个页签，默认不干扰日常查看。
3. 执行动作与危险操作必须和只读数据区分开。
4. 表格默认显示关键列，长表限制高度。
5. 需要频繁刷新的数据使用短缓存或手动刷新。
6. 每次页面结构变化必须同步写入 `changelog.md`。
