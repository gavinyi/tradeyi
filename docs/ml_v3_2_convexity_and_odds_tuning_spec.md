## 一、 现象发现与核心量化归因

在 2026-10-24 对生产环境 564 笔期权真实交易样本进行 A/B 回测时发现：
- **全量周期（90天）**：ML 模型总收益 258.12% 跑赢规则组 236.49%，胜率提升 7.08%，五档单调性（Q1 +$262 ➔ Q5 -$59）成立；
- **近 30 天切片**：规则组总收益 18.25%、盈亏比 3.63；而 ML 组总收益仅 10.63%、盈亏比降至 1.87（触发准入红灯）。

### 根本数学病因（胜率陷阱 Win-Rate Trap）
1. **二分类目标抹平非对称赔率**：
   - 现行目标变量为单一二分类 $y = \text{is\_profitable} \in \{0, 1\}$；
   - 随机森林分裂节点时，一笔 **+$555 的超级肥尾大肉单** 与 **+$5 的微利单** 权重等同；
   - 模型本能地追求降低 Gini 不纯度，学到了“过度规避波动、挑选胜率 60% 但盈亏比极低标的”的防守模式；
   - 导致在 9 月下旬震荡转单边的大行情中，ML 模型将具有高赔率弹性的标的（如 AMD/GLD 大盈利单）判定为低置信度（打分 0.41~0.47）而误杀，总利润跑输了敢吃大波动的规则组。
2. **绝对行权价的量纲污染**：
   - `strike_price`（绝对行权价）在特征重要性中占比高达 **24.18%**；
   - 绝对股价并非金融有效特征，导致模型误将高股价标的与特定模式强行绑定，削弱了泛化能力。
3. **缺少凸性（Convexity）性价比因子**：
   - 模型缺少反映做多波动率核心杠杆弹性的 `gamma_to_theta`（单位时间衰减下的 Gamma 爆发力）与 `rv_iv_ratio`。

## 二、 Chief 评估结论与技术定性

**评估意见：Analyst 的分析与调优路线完全合适、极其专业，定案纳入后续 ML v3.2 迭代！**

1. **不可接受现状**：仅靠堆高胜率（79.6%）却以牺牲期权最核心的赔率（盈亏比腰斩）为代价，违背了 Long Gamma 捕捉非对称收益的策略初衷；
2. **技术路线闭环**：通过“样本收益加权 + 特征无量纲化 + 凸性因子注入”，能够使模型在保持较高胜率的同时，恢复对高赔率肥尾标的的敏感嗅觉。

## 三、 ML v3.2 调优实施路线图

### 阶段一：极简速效改造（样本收益对数加权 Sample Weighting）
- **改造位置**：`scripts/ml_train_symbol_scorer_v3.py`
- **实现算法**：
  在 `model.fit(X, y, sample_weight=sample_weights)` 传入动态样本权重：
  $$w_i = \ln(1 + |\text{window\_net\_pnl}_i|)$$
- **预期收益**：
  使捕获到 +$500 以上大肉单的样本权重提升 5~8 倍，强迫决策树在分裂时高度倾斜于高赔率候选标的。

### 阶段二：特征工程清洗与凸性性价比因子补齐
1. **剔除量纲污染**：
   - 移除 `strike_price`；
   - 引入标准化的虚实值偏离度：
     $$\text{Moneyness} = \frac{\text{Underlying Spot Price}}{\text{Strike Price}} - 1$$
2. **注入凸性因子**：
   - 引入做多波动率性价比指标 `gamma_to_theta = abs(gamma / (theta + 1e-6))`；
   - 引入隐含波动率溢价倒数 `rv_iv_ratio = realized_vol_20d / (implied_vol + 1e-6)`。

### 阶段三：入场决策门禁联动（Top-K + Minimum Score Threshold）
- 在选品层引入最低打分门槛 `ml_score >= 0.55`（过滤 Q4/Q5 期望为负的垃圾区间）；
- 当某日全市场期权打分均未达标时，触发策略**主动空仓等待（Reduce-Only）**，不建新仓、只跟进已有持仓退出，进一步压缩最大回撤。

## 四、 验收与生产准入门槛

调优后的 v3.2 模型必须在我们上线的 **「规则 vs ML 对照回测大屏」** 满足以下硬性指标方可晋级覆盖：
1. **全周期与 30 天切片双跑赢**：ML 组在全量周期与最近 30 天切片下的累计收益率**均高于纯规则组**；
2. **盈亏比不劣化**：ML 组整体盈亏比保持在 **$\ge 2.0$**，杜绝胜率陷阱；
3. **五档单调性成立**：Q1 最高分档收益与胜率必须显著且单调高于 Q5 档位；
4. **最大回撤受控**：回撤相比规则组不恶化（$\le 1.1\times$）。
