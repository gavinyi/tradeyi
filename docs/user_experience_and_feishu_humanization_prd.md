## 一、 需求背景与目标

### 1. 痛点复盘
系统在底层多租户隔离、执行网关和交易安全门禁上已具备机构级健壮性，但在**面向交易员的产品化封装与交互体验**上仍存在典型的“研发直接倒底层数据”痕迹：
1. **飞书通知“天书化”**：虽然初步加上了中文标题，但正文与明细中仍充斥着如 `OPTION_LIFECYCLE_RISK`、`DAILY_LOSS_KILL_SWITCH` 等技术代码，缺少通俗的“发生了什么、对我资金有什么影响、我该点哪里处理”三要素；
2. **环境切换暴露裸端口号**：侧边栏按钮直接显示 `8501`、`8601`，且写死 `http://localhost:8601`，用户通过内网 IP 或域名远程访问时，点击会因跳转至 localhost 导致网络断连打不开；
3. **风控核心口径前端黑盒**：用户最关心的“单笔硬止损 $300 / 比例 -25%”在「风控中心」前端没有直接的设置卡片和留痕视图，用户无法感知当前真实生效限额；
4. **测试环境冷启动空白**：进入测试环境后，由于本地数据库为空，导致部分监控与持仓卡片缺少基础对照数据。

### 2. 产品目标
对齐工业级商业量化系统（如 富途牛牛机构版、盈透 TWS、Bloomberg PORT）的体验标准：
- **消息卡片“人话三要素”**：一目了然看懂**业务事实**、**资金影响**与**明确指引**，彻底消除英文代码恐慌；
- **环境穿梭无感化**：屏蔽底层端口，自动适配访问主机名，防呆视觉警示；
- **风控限额透明化**：双层止损口径（相对 -25% + 绝对 $300 兜底）在 Web 界面可见、可设、留痕可查。

## 二、 详细功能规格说明

### 模块一：飞书推送卡片深度「人话化」重构 (P0)

#### 1. 告警卡片结构重构（必须具备四层标准结构）
飞书富文本/交互卡片严格统一为以下层级，杜绝任何裸露技术字段：
1. **第一层：标题栏（Header）**
   - 格式：`{Emoji状态} 【{严重级别}】{中文通俗事件名}`
   - 例如：`🚨 【紧急风控】账户触发单日亏损急停刹车`、`⚠️ 【行权预警】期权即将到期，存在正股交割缺口`、`🟢 【对账恢复】三账持仓已重新对齐`
2. **第二层：业务事实（What Happened）**
   - 用通俗人话讲清楚发生了什么，带出核心标的、关联租户/账户与关键数值；
   - 例如：“富途实盘主专户（..9109）持有的 `META 10-30 看跌期权` 浮动亏损达到 $366，触碰设定的 $300 止损线。”
3. **第三层：资金与系统影响（Impact & Risk）**
   - 讲清楚对交易员当前的实际影响；
   - 例如：“【系统当前动作】已自动向交易所提交限价平仓单以锁定风险；持仓平仓不占用买入额度，新开仓功能仍处于保护中。”
4. **第四层：交易员行动指引与直达链接（Action & Navigation）**
   - 明确告知交易员下一步做什么，并提供按钮直达；
   - 按钮：`[ 🔍 前往查看该持仓明细 ]` 或 `[ 🎛️ 前往风控中心 ]`。

#### 2. 全量核心事件中文字典与解析模板
| 事件代码 (技术内部使用) | 中文人话名称 | 核心解释 (人话) | 建议交易员动作 |
| :--- | :--- | :--- | :--- |
| `DAILY_LOSS_KILL_SWITCH` | 🛑 **账户触发单日亏损急停** | 今日浮亏触及预设日限额，系统已自动刹车阻断所有新买入 | 禁止开新仓；现有持仓止盈止损仍照常托管 |
| `OPTION_LIFECYCLE_RISK` | ⚠️ **期权临期正股交割风险** | 持仓期权距到期不足设定天数且处于价内，行权将导致做空/做多正股 | 建议及时平仓锁定利润，防被动行权交割 |
| `LEDGER_MISMATCH` | 🚨 **三账持仓核算不一致** | 券商真实仓位与本地策略账本出现差异，已自动挂起该标的 | 登录后台核验成交，可点击“按富途持仓同步” |
| `REAL_TRADE_REJECTED` | ⛔ **实盘委托被安全门禁拦截** | 委托触碰安全网（如超额、无确认码或策略非白名单） | 检查实盘日限额与确认码会话状态 |
| `OPEND_DISCONNECTED` | 🔌 **行情网关通信中断** | 本地 OpenD 网关掉线，无法接收盘口与报单 | 检查本地 OpenD 程序与海外代理连接 |
| `PAPER_DAILY_LOSS_WARN` | 🟡 **模拟盘亏损达预警线** | 模拟沙盒当日亏损达到预警阈值（$25,000） | 仅做前向推演监控，不阻断模拟盘后续验证 |
| `HARD_STOP_LIMIT_INVALID` | ❌ **策略止损参数非法** | 策略缺少止损限额配置，系统拒绝对其开仓 | 前往策略控制台补齐止损限额参数 |
| `STRATEGY_NEW_ENTRY_BLOCKED`| ⏸️ **策略已开启只减仓模式** | 该策略处于「暂停新开仓」状态，已拦截本次新增买入 | 正常现象，如需开仓请在策略控制台取消勾选 |

### 模块二：生产 / 测试双环境穿梭体验打磨 (P1)

#### 1. 隐藏底层裸端口，优化为人话标签
- 在侧边栏顶部切换区：
  - 生产环境展示：**`🧪 切换至仿真实验区`**（原 `切换至测试环境 (8601)`）；
  - 测试环境展示：**`🏭 切换至生产正式环境`**（原 `切换至生产环境 (8501)`）；
  - 彻底隐藏 `8501` / `8601` 裸露技术端口号。

#### 2. 动态 Host / IP 自适应跳转（杜绝 Localhost 踩坑）
- **痛点**：目前直接写死 `http://localhost:8601`，当用户在平板、手机或局域网其他电脑通过 `http://192.168.x.x:8501` 访问时，点击会跳转到设备自身的 localhost 导致网络打不开。
- **产品规范**：
  - 切换链接必须基于浏览器当前访问的 Hostname/IP 进行动态组装（如当前通过 `192.168.1.5:8501` 访问，点击切换自动跳到 `192.168.1.5:8601`）。

#### 3. 测试环境全景视觉防呆标识
- 测试环境侧边栏与主视窗顶部保持鲜明标识：
  - 标明黄色醒目徽章：`🧪 当前处于仿真测试实验区（测试数据，不连真金）`；
  - 避免交易员在多标签页操作时误将测试环境当实盘，或将实盘当测试。

### 模块三：风控中心双层止损口径前端可视化 (P1)

#### 1. 界面呈现位置：`pages/7_risk_center.py`（风控中心）
在风控中心新增独立卡片：**「🎯 波动率策略双层止损口径（定案规范）」**

| 参数配置项 | 当前生效值 | 控件类型 | 业务说明 |
| :--- | :---: | :---: | :--- |
| **相对止损比例 (主防线)** | **`-25.0%`** | 百分比数字输入框 | 随权利金规模自动缩放，亏损达到本比例触发市价止损 |
| **单笔最大亏损 (兜底上限)**| **`$300.00`** | 美元金额输入框 | 大仓位兜底硬线，两者取较紧者（OR 逻辑）先生效 |
| **生效逻辑说明** | `较紧者优先` | 只读标签 | 小仓位（如 $300 权利金）由 -25%（亏 $75）先止损；大仓位（如 $2000 权利金）由 $300 先止损 |

#### 2. 改动审计与保存
- 修改保存后，写入数据库配置，并在下方直观展示**最近 5 次风控参数调整记录**（操作人、改动前后值、改动时间），保持可追溯。

## 三、 验收标准与交付物

1. **飞书通知验收**：
   - 触发一次模拟告警（如 `DAILY_LOSS_KILL_SWITCH` 或 `OPTION_LIFECYCLE_RISK`），飞书群卡片标题与正文 100% 为人话中文，清楚展现事实、影响与行动指引，无生硬英文代码。
2. **环境穿梭验收**：
   - 局域网/本机通过非 localhost IP 访问生产页面，点击切换按钮，能以相同 IP 顺畅无缝跳转至测试环境，无端口割裂感。
3. **风控中心可视化验收**：
   - 打开「风控中心」页面，清晰展示 `-25%` 与 `$300` 双层止损卡片，管理员修改后能成功保存并留痕可查。
