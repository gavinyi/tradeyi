# 币量化成熟框架对标与实施路线

## 对标项目

| 项目 | 借鉴点 | 本项目采用方式 |
|---|---|---|
| Freqtrade | Dry-run、回测、Hyperopt、protections、pair lock、lookahead analysis | 保留 Shadow/OKX Demo 双模式；增加冷却、回撤保护、标的锁和前视检查 |
| Jesse | 多标的/多周期、智能订单、Benchmark、Monte Carlo | 增加多周期确认、基准对比和交易顺序/路径扰动压力测试 |
| NautilusTrader | 研究与实盘同语义、确定性事件引擎、订单状态与风险引擎 | 信号纯函数在回测和运行服务共用；补订单事件、对账和重启恢复 |
| Hummingbot | 连接器、长期运行、监控、通知和多交易场所 | 保持 OKX 独立 Broker；复用现有心跳、告警、日志和服务控制 |

## 已实施的第一批

1. 每轮从币策略虚拟持仓读取数量和成本，不再假设持仓为零。
2. Shadow 买入记录数量、价格和金额；再次扫描不会重复开仓。
3. Shadow 退出清理虚拟持仓和峰值状态。
4. 增加独立盈利保护参数：启动比例、允许回吐、最低锁定盈利。
5. 总览展示 Shadow 持仓，配置页开放盈利保护参数。

## 第二批完成状态

1. **订单状态与对账**：已实现 OKX Demo 待成交去重、系统订单成交明细和部分成交聚合；
   服务重启按 `cq` 客户端订单号重建策略持仓。
2. **Protections**：已实现退出冷却、最大同时持仓、组合最大敞口和组合最大回撤熔断。
3. **退出完善**：已实现两档分批止盈、最长持有、趋势反转和连续波动收缩退出。
4. **研究验收**：已实现滚动 Walk-forward、权益路径 Monte Carlo 和前视成交检查。
5. **运营能力**：总览已展示待成交、历史订单、系统成交、Shadow 持仓和中文决策。

仍不在当前范围：跨币种相关性模型、稳定币信用风险评分、WebSocket 逐笔订单推送和真实盘。

## 不采用的部分

- 不直接引入完整 Freqtrade/Jesse/NautilusTrader 作为第二套运行时，避免与现有账户、审批、
  诊断和 Streamlit 系统重复。
- 不复制 GPL 项目代码，只借鉴公开的产品和架构思路。
- 不因框架支持而开放欧易真实盘、杠杆、永续或做空。
