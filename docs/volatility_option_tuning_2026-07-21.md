# 波动率期权策略调优记录

日期：2026-07-21

## 近期运行判断

最近几次运行显示，波动率期权策略已经能完成“雷达触发、候选生成、策略决策、Shadow 撮合”的主链路，但稳定性不足。问题不是单纯条件过严，而是触发后合约表达没有持续维护，导致旧合约盘口变差、行情过期、方向变化或信号解除后，系统仍然盯着原合约。

近期本地记录摘要：

- 雷达触发：约 334 次。
- 策略 BUY 决策：约 420 次。
- Shadow 成交：13 笔。
- 订单意图：18 笔。
- 主要阻断：期权行情过期、盘口不可用、方向未确认、冷却中、候选字段异常。

## 主要问题

1. 方向确认偏滞后

   当前方向判断依赖日内涨跌、5 日动量和 20 日趋势。强日内波动场景中，5 日和 20 日趋势可能滞后，导致“方向分未达到绝对值 2”。

2. 旧合约容易失效

   雷达触发后会生成一个期权活动，但后续如果该合约盘口变宽、报价过期、IV 成本变差或不再是最佳候选，系统之前不会主动替换。

3. 行情新鲜度阻断集中

   多次出现“期权行情已过期”“盘口不可用”“价差过大”。这些情况下应该优先尝试同方向更优合约，而不是只 HOLD 原合约。

4. 冷却机制需要按退出原因区分

   止损退出、止盈退出、波动收缩退出、到期滚动退出的含义不同，冷却时间不应完全相同。

5. 执行可观测性仍需增强

   页面和诊断中心应该持续展示当前活动合约、正股信号、是否仍是最佳候选、替换原因、最近维护时间和候选排名。

## 本轮改造目标

将波动率期权策略从“一次性生成合约”升级为“持续维护最佳期权表达”。

原则：

- 空仓时可以自动换到当前最佳合约。
- 持仓中不自动换合约，避免隐式换仓。
- 有待成交订单时不换合约，避免重复下单。
- 原合约报价过期、盘口不可用、不再合格、方向变化或新候选明显更优时替换。
- 维护频率受限频保护控制，默认至少间隔 5 分钟。

## 后续建议

- 将方向确认升级为“强日内优先，趋势辅助”。
- 给冷却机制按退出原因配置不同冷却时间。
- 在波动率策略页增加“当前最佳候选 vs 当前活动合约”的对比看板。
- 在诊断中心增加“合约维护/替换时间线”。
