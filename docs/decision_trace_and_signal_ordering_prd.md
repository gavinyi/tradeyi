- **参考价** `$21.75`；**基础期权费预算** `$4,500`；**生效预算** `$9,000`；**单手风险预算** `$761.25`

### 3. 为什么交易员「没见到数据」——三个产品级缺口
1. **决策依据无界面呈现**：理由、风险档位、参考价、预算、市场条件全部只写进 `metadata_json`，**没有任何用户可读的界面承载**；
2. **信号记录时序倒挂**：雷达「信号检出」告警产生于 21:43:50，**晚于 21:39:21 的成交 4 分 48 秒**。交易员按时间顺序看，永远看不到「下单前的依据」——因为依据在时间线上根本不存在于下单之前；
3. **告警未触达（最严重）**：`alerts` 表显示 `OPTION_LIFECYCLE_RISK` 与 `VOLATILITY_SIGNAL_DETECTED` 两条记录的 **`delivered = 0`**。即：**系统自己检出的「交割将造成 100 股裸空」风险，从未推送到飞书群**。交易员不是「没看到界面」，而是**被系统彻底静默**。

## 二、 详细业务需求规格

### 1. 决策溯源人话化呈现（Decision Trace）
新增「决策溯源」视图（可挂在持仓详情、订单流水中，可展开）：
- **一笔订单卡片必须包含**：
  - 策略名称与可读中文别名（如 `volatility_long_gamma` → `波动率·长 Gamma 期权策略`）；
  - **入场/出场理由（人话）**：如「第 0 轮首次入场：动态波动与方向确认后首次入场」；
  - **风险档位**：`强波动` → 附带说明「高波动环境，期权费预算上调至 2 倍」；
  - **当时的市场条件**：触发时的波动率、正股方向、信号来源（雷达/策略自检）；
  - **预算与成本**：参考价、预算、实际成交均价、滑点；
  - **风险提示**：如「该合约为价内，到期交割将产生 100 股正股敞口」。
- **信息分级**：摘要行只给「理由 + 档位 + 盈亏」；完整决策链路折叠，供追溯。

### 2. 信号时序一致性（Signal Ordering Guarantee）
- **强约束**：任何下单动作，其**决策依据（信号检出/策略判定）必须先于或同刻写入并可被检索**；
- **实现要求**：
  - 策略判定与信号记录使用**同一时间戳源**（决策时刻，而非日志落盘时刻）；
  - 决策记录写入 `decisions` 表，字段含 `decision_at`、`signal_source`、`rationale`、`market_context`；
  - 下单意图 `order_intents` 通过 `decision_id` 外键关联，形成**不可断裂的「信号 → 决策 → 下单」链路**；
  - 前端决策溯源视图按 `decision_at` 排序，保证「依据永远在动作之前」。

### 3. 告警触达完整性（Alert Delivery Integrity）
- **原则**：**凡是系统判定为 ERROR 级的事件，必须有可验证的触达凭证**；记录 `delivered=0` 即视为触达失败，必须进入待办；
- **具体要求**：
  - `OPTION_LIFECYCLE_RISK`（交割/行权敞口风险）**加入飞书群告警白名单**——这是真金敞口事件，不应只走 webhook；
  - 新增「告警触达审计」：每 30 分钟巡检统计过去周期内 `severity IN ('ERROR','CRITICAL')` 且 `delivered=0` 的记录，**置顶红字暴露**并计入运维 KPI；
  - 告警卡片必须包含**合约名**（修复 Ops 已识别的 P3 第 32 项）；
  - 触达失败时降级路径：webhook 失败 → 飞书群卡片 → 界面常驻红条，三级兜底，不允许三级全静默。

### 4. 实盘开仓前置风险提示（Pre-trade Risk Notice）
- 对**价内（ITM）期权买入**，若预期到期将产生正股敞口（如 100 股裸空），**在下单前**于界面弹出明确提示，并要求确认，而非事后告警；
- 对**已识别的交割缺口**，在持仓卡片上常驻展示「预计交割：做空 100 股 META」。

## 三、 验收标准
1. 任意一笔订单可在界面一键展开完整决策链路（理由、档位、市场条件、预算、滑点）；
2. 决策记录时间戳**严格早于或等于**关联订单的 `created_at`（时序倒挂用例必须失败）；
3. 人为制造 `OPTION_LIFECYCLE_RISK` 事件，验证飞书群**必须收到**含合约名的卡片；
4. 巡检报告可输出「过去 30 分钟 ERROR 级未触达告警清单」，且该清单为空为常态。
