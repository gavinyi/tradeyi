# ML 与规则策略对照回测与模型满足度验证产品需求规格说明书 (PRD)

> **文档版本**: 1.0 (Production PRD)  
> **制定日期**: 2026-10-24  
> **负责人**: Product (产品经理)  
> **适用范围**: 期权多头波动率策略 (Volatility Long Gamma) 选品模型验证  
> **状态**: 待 Architect 出技术设计 → Chief 审批签字与计划排期

---

## 一、 需求背景与业务定位

在量化投资体系中，**绝对不能盲信黑盒模型的离线训练指标（如纯看训练集的 AUC 或单样本准确率）**。必须在历史真实盘口数据上并行回放两套选品逻辑：**一套纯规则基准，一套 ML 增强模型**。通过真实的交易盈亏、胜率、回撤以及分层收益单调性，客观量化检验 ML 到底有没有带来正向超额收益 (Alpha)，并给出明确的“满足度准入判定”。

---

## 二、 核心功能与四大视图规格

### 1. 核心绩效对决看板（A/B Benchmark Matrix）
在相同历史期权数据与行情窗口（如最近 30 天 / 60 天 / 90 天）下，并行回放两套逻辑：
- **基准组（规则打分）**：仅按 `volatility_quality_score` 规则进行选品与开仓；
- **对照组（ML 增强）**：结合 `ml_score` 与 `ml_adjusted_score` 重新排序选品。
- **并列对比核心指标**：
  - **总累计收益率 (Total Return %)**
  - **交易胜率 (Win Rate %)**
  - **盈亏比 (Profit/Loss Ratio)**
  - **最大回撤 (Max Drawdown %)**
  - **夏普比率 (Sharpe Ratio)**
  - **平均单笔盈亏 (Avg PnL per Trade)**
  - **净值曲线叠加图**：一目了然看相对跑赢还是跑输。

### 2. 分数预测能力与分层单调性检验（“分数看 ML 满足要求不”）
- **Rank IC 评价**：
  - 计算 `规则评分 ↔ 未来期权真实收益` 的相关系数；
  - 计算 `ML 评分 ↔ 未来期权真实收益` 的相关系数；
  - 只有当 ML 的 IC 显著高于规则时，才证明模型具备真实预测力。
- **五档分层收益柱状图（Quintile Performance）**：
  - 将所有候选期权按 ML 分数从高到低分成 5 组（Top 20% 到 Bottom 20%）；
  - **满足度铁律（单调性）**：最高分组（Q1）的平均实际收益必须显著高于最低分组（Q5）；若高分组亏损、低分组大赚，系统自动标红判定模型“反向失效/过拟合”。

### 3. 选品分歧与归因明细表（Divergence Ledger）
下钻表格清晰展示交易员最关心的“具体单子差异”：
- **ML 避雷案例（Positive Divergence）**：
  规则排在前列、但 ML 判定低分打压的标的。后验展示这些标的是否确实大部分亏损（成功避坑）；
- **ML 淘金案例（Alpha Discovery）**：
  规则排在靠后、但 ML 预测高分提拔入选的标的。后验展示这些标的是否确实带来了超额收益；
- **明细字段**：标的代码、入场时间、规则分、ML分、分值差、实际平仓收益率、退出原因。

### 4. 自动化生产准入判定卡（Production Readiness Checklist）
在看板顶部以红绿灯卡片形式直接给出结论：
- 🟢 **满足实盘接入要求 (Recommended for Production)**：
  - 判定条件：① 回测总收益高于规则组；② 胜率提升 ≥ 3%；③ 最大回撤不劣于规则组；④ 五档分层单调性成立。
- 🔴 **不建议上线（Keep Rule-Based）**：
  - 若未满足以上指标，页面醒目标注具体未达标原因（如：“ML 胜率低于规则基准 2.1%，存在回撤扩大风险”），杜绝盲目上真金。
