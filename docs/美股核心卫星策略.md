# 美股核心—卫星策略

本策略将宽基ETF作为长期底仓、经人工基本面审核的龙头股作为卫星增强仓，并常态保留至少
30%现金或防守资产。目标不是短期暴富，而是在控制最大回撤的前提下获得长期复利。

核心规则：

- SPY/VOO/QQQ 是核心仓，其他观察列表标的是卫星仓；
- 股票总仓位不超过70%，单只卫星仓上限不超过5%；
- SPY 200日均线判断风险状态；
- 距60日高点回撤8%/16%/25%时逐层提高目标仓位；
- 跌破200日均线后等待重新站上20日均线，避免机械左侧抄底；
- 相对200日均线偏离25%/40%时分层减仓；
- 基本面恶化时必须人工从观察列表移除，程序不会替代财报和护城河分析；
- 仅使用美股模拟账户，默认不自动提交订单。

具体运行方式参见项目根目录 README 的“核心—卫星策略”章节。
